# References

This folder is used to track every source that is reviewed or cited and to store a copy
of each source document.

## What should be placed here

- `literature_matrix.xlsx` - the tracking sheet for all reviewed and cited sources
- `papers/` - PDF copies of the reviewed and cited sources

## Suggested literature matrix columns

Author/Year, Title, Theme, Key finding, Contribution, Identified gap, How used, Citation.

## Maintenance

A row should be added as soon as a source is found useful. PDF files should be named
consistently (for example, `AuthorYear.pdf`) and kept in sync with the matrix. This
material forms the basis of the literature review and the final reference list.
