# Templates

This folder holds blank starter documents so that formatting remains consistent across
the project.

## What should be placed here

- Cover page starter
- Proposal document starter
- Thesis document starter
- Presentation deck starter
- Literature matrix sheet starter
- Diagram starter file

## Maintenance

Templates should not be filled in directly. A copy should be taken into the relevant
working folder and edited there, leaving the original blank. A template should be
updated only when the official format it is based on changes.
