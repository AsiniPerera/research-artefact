# Meta

This folder holds the documents that define the project task - the material that is
provided rather than produced. These act as the reference point for what the project
must deliver.

## What should be placed here

- Coursework or module descriptor
- Marking rubric / assessment criteria
- Submission deadlines and project calendar
- Module guidelines or briefing material

## Maintenance

The contents should be treated as read-only reference material. They should be replaced
only when an updated version is officially issued, and should not be edited.
