# Dissertation Drafts

This folder is for capturing written ideas at every stage — from early seed thoughts and
rough notes through to polished drafts ready for submission. Each subfolder corresponds
to a different type of written output, but all of them welcome incomplete, in-progress
text. Writing things down early, even messily, is the point.

## Structure

- `Proposal/` - seed ideas and evolving drafts for the project proposal
- `Thesis/` - ongoing thesis writing, from scattered notes to structured chapters
- `Presentations/` - slide outlines, speaker notes, and drafts for pitches and defenses
- `Final/` - submission-ready versions only (moved here when complete)

## How to use these folders

Think of `Proposal/`, `Thesis/`, and `Presentations/` as idea spaces. Drop in rough
notes, half-formed arguments, outlines, and fragments — anything written is better than
nothing. Text seeds left here can be developed into full sections over time.

`Final/` is the exception: only place a document here when it is ready to submit. The
working copy should be a `.docx` file linked to OneDrive so that supervisor feedback and
revisions are synced automatically. Keep **Track Changes** turned on at all times in this
file so that every edit is attributed and reviewable. Export a PDF snapshot at each
submission milestone and do not modify it afterwards — it serves as a permanent record of
what was submitted.

## Maintenance

There is no need to keep these folders tidy while work is in progress. When a document
reaches a milestone (submitted, presented, or approved), move the final version to
`Final/` and note the date in the filename or a short accompanying text file.
