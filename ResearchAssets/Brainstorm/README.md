# Brainstorm

This folder is intended as an informal working space for early thinking, before the
project takes formal shape.

## What should be placed here

- Initial research ideas and direction
- Scope iterations and refinements
- Title options, including those considered and dropped
- Mind maps, sketches and problem-space notes

## Maintenance

Content should be kept loose and dated. Rejected ideas should be retained rather than
deleted, as they are useful for explaining and defending design decisions later.
